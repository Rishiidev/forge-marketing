# Legacy static site

This directory is the untouched baseline site (see the `Baseline: import
existing Forge marketing site, unmodified` commit on `main`), moved here
verbatim to make room for the Next.js rebuild at the repository root.

Nothing in this directory has been edited — only relocated. It stays as
a reference for content, copy, and behavior while the rebuild is in
progress. See `../docs/forge-business-rules.md` for what has been
extracted from it as the business source of truth, and
`../docs/decisions.md` for the ADR recording this move.

Do not deploy this directory. It is not wired into the new build.
